Executive summary

What failed

Fixed

PRS current-session bill statuses were stale

Local generated and DB records stopped at April 16, 2026 introduction events for the Constitution 131st Amendment Bill, the Delimitation Bill, and the Union Territories Laws Amendment Bill. A narrow PRS Session Wrap sync now records April 17, 2026 terminal outcomes for only those three bills, corroborated by the Ministry of Parliamentary Affairs Budget Session 2026 press release and PRS Vital Stats.

Source failure

Sansad legislation JSON returned HTTP 500

The official Sansad JSON API check failed with HTTP 500. Existing scripts would fall back to a public mirror, so a broad Sansad refresh was not safe enough to run as a source-of-truth update.

Ambiguous

Parliament Digital Library transcript discovery failed

Source discovery could not fetch the PDL/eparlib committee-report and transcript-search URLs. That means debate freshness beyond existing manual rows could not be proven from PDL during this run.

Fixed

data.gov source metadata was stale

Source discovery found Rajya Sabha questions Session 267. The generated metadata was refreshed and the data.gov question/timeline rows were re-upserted.

Fix sequence

Recommended implementation order

1. Current-session PRS delta ingestion completed

  1. Fetches the PRS Budget Session 2026 Session Wrap.
  2. Extracts bill title, introduced date, outcome, source URL, and affected house.
  3. Maps the voted-down constitutional amendment and the two infructuous linked bills to terminal local bill/action/timeline records.
  4. Dry-runs against the DB, then upserts only the three affected bills and their PRS current-session rows.

2. Harden source discovery

  1. Add retry/backoff around Sansad and PDL fetches.
  2. Separate authoritative API success from mirror fallback success in generated metadata.
  3. Report source failures as structured JSON so audits can diff failures over time.

3. Add governance review workflow

  1. Document the official/manual source fields required for each state.
  2. Run a manual review when source pages change or elections/oath notices happen.
  3. Update last_verified only after values are checked, then run verification.

The data.gov refresh was completed with narrow commands: pnpm run discover:sources:write, pnpm run sync:data-gov, pnpm run verify:data-gov, and pnpm run db:upsert:data-gov. The PRS current-session fix was completed with pnpm run sync:prs-current-session, pnpm run verify:prs-current-session, and pnpm run db:upsert:prs-current-session.
